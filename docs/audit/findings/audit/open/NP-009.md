# Throwing callback registered via fieldPaths escapes and aborts logging

## Problem

`maskValue` invokes `customCallbacks[$path]` with no try/catch (only
`processCustomCallbacks` is guarded).

## Evidence

A path present in both `fieldPaths` and `customCallbacks` with a throwing callback
propagates out of `__invoke`.

## Impact

Log record lost; app may crash inside the logger.

## Fix

Wrap the callback invocation in `maskValue` in try/catch mirroring
`processCustomCallbacks`.
