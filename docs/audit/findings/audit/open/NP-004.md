# Array field value under MASK_REGEX stringified to literal "Array"

## Problem

The MASK_REGEX branch does `(string) $value` on arrays.

## Evidence

`{user: ['email' => 'a@b.com']}` with a MASK_REGEX fieldPath emits an
"Array to string conversion" warning and stores the literal `'Array'`.

## Impact

Nested data destroyed; masking intent silently lost.

## Fix

Recurse into arrays (or `json_encode`) before applying regex, matching
`AbstractMaskingStrategy::valueToString`.
Status note: Pre-existing; dedicated-PR scope.
