# Dependency and permission hygiene (grouped)

## Problem

(a) `illuminate/*: "*"` with `minimum-stability: dev` tests a moving target;
(b) pr-lint has `contents/actions/issues: write` for a lint job; (c) stale.yml carries
unused top-level perms and a caller-less `workflow_call`; (d) psalm.xml/phpstan.neon carry
~25/~30 blanket suppressions while CLAUDE.md declares zero-tolerance.

## Evidence

Config as written.

## Impact

Larger attack/drift surface; policy and config contradict each other.

## Fix

Constrain illuminate majors; trim workflow perms; document the suppressions as approved
exceptions or burn them down.
