# JsonMasker::fixEmptyObjects corrupts string contents

## Problem

Blindly `preg_replace`s the first N `[]` occurrences in encoded JSON, counting `{}`
in the raw original, with no structural awareness.

## Evidence

`{"a":"x[]y","b":{}}` → `{"a":"x{}y","b":[]}` — the `[]` inside a string value was
rewritten and the genuine empty object emitted as `[]`.

## Impact

Any log payload containing `[]`/`{}` inside string values is silently mutated.

## Fix

Decode with `json_decode($json, false)` to preserve empty-object identity instead of
regex surgery on encoded output.
