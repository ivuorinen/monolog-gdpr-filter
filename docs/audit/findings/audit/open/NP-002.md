# Depth guard bypassable via DataTypeMasker 'recursive' → segfault on deep arrays

## Problem

`processArrayValue` calls `dataTypeMasker->applyMasking`; with `array => 'recursive'`
configured, `maskArray` re-enters `recursiveMaskCallback($value, 0)`, resetting depth to 0 at
every level, so `maxDepth` never trips.

## Evidence

200k-deep nested array with `['array' => 'recursive']` → PHP segmentation fault
(exit 139) in PoC.

## Impact

Remote-triggerable crash from attacker-controlled log context.

## Fix

Thread the real current depth into the recursive-array mask (`$currentDepth + 1`);
enforce `maxDepth` on that path.
