# Codecov upload failures invisible

## Problem

`fail_ci_if_error: false` plus secret token means missing/rotated CODECOV_TOKEN
silently skips upload forever.

## Evidence

Config as written.

## Impact

Coverage tracking dies silently.

## Fix

`fail_ci_if_error: true` for push events, or alert on upload failure.
