# Duplicate coverage pipelines on identical triggers

## Problem

Both run `composer test:ci` producing coverage.xml on push/PR to main.

## Evidence

Two full test runs per event with two different consumers (Codecov vs
artifact+PR comment).

## Impact

Doubled CI time; drift between two coverage sources of truth.

## Fix

Merge into one workflow; run tests once, feed both consumers from the same coverage.xml.
Status note: Workflow-consolidation design choice left to the maintainer.
