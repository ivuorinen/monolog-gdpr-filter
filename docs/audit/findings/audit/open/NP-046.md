# Generated literal-type docblocks on test doubles add churn

## Problem

Dozens of `@psalm-return 'plugin-1'`-style docblocks on trivial anonymous-class
methods; several place `#[\Override]` before the docblock, detaching it in some tools.

## Evidence

Diff of PR #115.

## Impact

Docblocks desynchronize on the next value change and bury real diffs.

## Fix

Drop literal `@psalm-return` docblocks on test doubles; rely on native return types.
