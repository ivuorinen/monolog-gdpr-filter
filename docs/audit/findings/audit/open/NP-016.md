# Strategy layer not wired into GdprProcessor (drift source)

## Problem

Public "@api" subsystems are parallel implementations not referenced by the core
pipeline; `FieldPathMaskingStrategy` handles custom regex correctly while the wired
`ContextProcessor` does not (NP-003).

## Evidence

Grep shows no references from the core pipeline.

## Impact

Two masking paths drift; correct behavior exists but is unreachable.

## Fix

Consolidate onto one masking path, or add cross-tests asserting identical output.
