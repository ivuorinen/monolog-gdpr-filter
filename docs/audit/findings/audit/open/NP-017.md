# Tautological assertInstanceOf(Throwable) in catch blocks

## Problem

The caught value is a Throwable by definition.

## Evidence

Assertion can never fail.

## Impact

Masks which exception types are actually acceptable.

## Fix

Assert the specific expected exception class(es); rethrow unexpected ones.
