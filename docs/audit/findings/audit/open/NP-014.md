# 16+ assertTrue(true) "does not throw" tests assert nothing observable

## Problem

Only prove no exception; silent acceptance of bad config still passes.

## Evidence

A validator that accepts-and-mangles input passes all of these.

## Impact

For validators guarding masking config, silent acceptance means unmasked data
downstream.

## Fix

Assert observable outcomes, or use an explicit `assertNoException`-style helper.
