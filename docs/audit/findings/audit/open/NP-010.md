# Callback runs twice when a path is in both customCallbacks and fieldPaths

## Problem

`processContext` calls `maskFieldPaths` (which prefers the customCallback) and then
`processCustomCallbacks` (which runs it again).

## Evidence

PoC shows callback invoked twice (`H(H(bob))`).

## Impact

Non-idempotent callbacks double-apply; audit logs duplicate.

## Fix

Process each path once; skip already-handled paths in `processCustomCallbacks`.
Status note: Pre-existing; dedicated-PR scope.
