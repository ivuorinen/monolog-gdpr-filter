# Message masking discarded if the masked result is '' or '0'

## Problem

The original message is returned when the masked result is empty or `'0'`.

## Evidence

Pattern `/secret-\d+/ => ''` leaves `secret-123` fully unmasked.

## Impact

Legitimate redaction-to-empty leaks the sensitive original.

## Fix

Track whether a replacement occurred (e.g. `preg_replace` count) instead of inferring
from the result string.
